# Final Reflection

This activity helped me understand how enterprise cloud infrastructure can be designed and managed using virtualization and containerization.

I learned how to create and configure an Ubuntu Server virtual machine using VirtualBox and connect to it remotely through SSH. I also learned how Docker and Docker Compose can be used to deploy multiple services as containers.

The WordPress and MariaDB containers demonstrated how application and database services can work together while using persistent storage for data protection.

I also learned the importance of server security. UFW was configured with a default deny incoming policy, while only the required SSH and HTTP ports were allowed.

The backup script and Cron scheduler demonstrated how system administration tasks can be automated. The health-check script also provided a simple way to monitor the application containers.

Overall, this activity improved my understanding of virtualization, containerization, networking, firewall configuration, persistent storage, automation, and enterprise cloud operations.
